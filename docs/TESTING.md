# 测试清单（1.1.0 · 2026-10-18）

环境：JVM 单元测试 + Android 14 (API 34) x86_64 模拟器。宿主机 KVM 不可用，模拟器以纯软件模式运行（极慢，系统频繁弹「无响应」），故真机交互测试只做了下列项。**全部测试均未使用真实 DeepSeek Key**，生成调用使用本地 mock 服务 `tools/mock_server.py`。

### 原有（1.0.0，约 27 项）

### 1.1.0 新增（`V110Tests.kt`）
- 作者主页 / 帖子识别（x.com / Twitter / 公众号主页 / 微博 / 知乎 / B 站 / YouTube / 小红书等）；保留路径（home/search/intent）不误判
- 主链接分类：内容平台帖子 → 来源；GitHub 仓库 / 网站首页 → 资源
- 来源与作者链接 `sendToModel=false`，全部仍入库
- `linksForModel` 排除来源；发给模型的标题去掉「某某 on X:」前缀；不再发送「原始来源链接」行
- 旧记录升级重分类（作者主页 → 来源；GitHub 主链接 → 资源；用户已确认的不动）
- 复制完整文案含标签、不含来源 URL；复制全部链接排除来源
- 安全网：来源编号 / URL、「原帖 / 作者主页」、@账号 → 提醒；邮箱等不误报
- 标签规范化 / 解析 / 合并 / 正文末尾 #标签 提取；OutputParser 读 tags 字段
- 提示词迁移：旧默认 → 新默认；已自定义 / 已迁移 → 不动
- 新默认提示词含「搬运分享者」「不提原发帖人」「tags」字段
- 备份 v2 标签往返；v1 备份仍可导入
- 封面排版：CJK/拉丁换行、行首禁则、字号适配、均衡换行、内容不含作者与链接
