# 更新记录

## 1.1.0（versionCode 2）· 2026-10-18
- 文案不再提及原发帖人：新默认提示词（搬运分享者口吻、聚焦资源、不编造体验、输出 tags 字段）；未自定义的提示词升级时自动迁移。
- 原帖 / 原始来源 / 作者主页链接归为「来源」：不发给模型，不进「复制完整文案」和「复制全部链接」，在应用内标注「来源，不进文案」；发送给模型的标题去掉发帖人前缀。
- 结果页安全网：文案含来源链接、「原帖 / 作者主页」字样或 @账号时提醒（不改文字）。
- 结果页重做：标题 / 正文 / 标签三区编辑，标签可删可加，链接与事实核查默认折叠。
- 「分享到小红书」：依次写入剪贴板三条 + 启动小红书或分享应用内生成的 3:4 封面图；设置页新增相关选项和默认标签。
- 数据库 v2（新增标签列），备份格式 v2（兼容 v1）。
- 链接保护机制不变：URL 仍由程序独立提取、编号、回填，模型不能改写。
